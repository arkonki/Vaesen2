# Original App Illustrations

encoded as WebP for deployment. These are new illustrations, not extracted
rulebook artwork. The Vaesen symbol remains the user's existing SVG asset.

## Nordic Manor

Asset: `nordic-manor.webp` (1600 x 800)

Use case: illustration-story. Asset type: wide original atmospheric banner for a Nordic folk-horror tabletop campaign web app. Create a new original ink-and-watercolor illustration, landscape aspect ratio approximately 2:1. Scene: a remote Scandinavian manor with towers beyond a pine forest at dusk, a narrow winding path, a tiny warm red lantern by a gate, wisps of fog. Antique natural-history engraving linework, restrained hand-painted sepia and weathered parchment washes, dark brown ink, muted moss green, faint oxblood accents. Lighter empty parchment on the left third, manor and pine silhouettes concentrated on the right two-thirds; detailed illustration that dissolves organically into cream paper at edges. Moody, quiet and mysterious, not gory or action-oriented. No text, no lettering, no logo, no border, no watermark. Not a copy of any existing game art or artist's illustration.

Use case: illustration-story. Asset type: original wide companion banner for the reference library in a Nordic folk-horror tabletop web app. Landscape ratio approximately 2:1. Quiet investigative atmosphere, realistic 19th-century objects, elegant detailed linework. No readable words, no lettering, no text, no logo, no watermark, no border.
